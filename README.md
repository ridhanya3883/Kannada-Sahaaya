# Kannada Sahaaya – Your Everyday Kannada Communication Assistant

## About the Project

Kannada Sahaaya is a web application that helps people who don't know Kannada communicate more easily in everyday situations.

The main idea behind this project is to make learning and using basic Kannada phrases easier, especially for people who are new to the language.

## Features

- **English to Kannada Translation:** Users can enter their own English sentences and get the Kannada translation.
- **Pronunciation:** Users can listen to the Kannada translation through audio.
- **Everyday Phrases:** Includes 50 useful Kannada phrases.
- **Different Categories:** Phrases are available for shopping, healthcare, transport and daily conversations.
- **Search:** Users can search for phrases they need.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Sarvam AI API

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Create a `.env` file and add your Sarvam API key:

```text
SARVAM_API_KEY=your_api_key
```

5. Run the application:

```bash
py app.py
```

6. Open `http://127.0.0.1:5000` in your browser.
